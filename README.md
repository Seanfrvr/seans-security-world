# Sean's Security+ World

Home for **Sean's Security+ Lab**, a self-contained CompTIA Security+ SY0-701 study app.

## Main files

- `index.html` — main study lab
- `manifest.webmanifest` — installable web-app metadata
- `sw.js` — offline/service-worker support
- `app-icon.svg` — app icon

## Notes

The lab is designed to work as a normal GitHub Pages site and can also support offline/installable use when the PWA files are present. Study progress is stored locally in the browser on the device being used.

This repository is intentionally separate from the main portfolio website repository.
