# Sean's Security+ World

Private home for **Sean's Security+ Lab**, a self-contained SY0-701 study app.

## Main files

- `seans-security-lab.html` — the full study lab
- `index.html` — lightweight launcher that opens the lab

## Notes

The lab is self-contained and can be opened directly in a browser for offline study. Progress is stored locally in the browser on the device being used.

This repository is intentionally separate from the public portfolio website repository.
